02
Technology
Python Tech Stack
Full replacement of Node.js/Express with a Python-native stack. FastAPI is chosen for its async performance, automatic OpenAPI docs, and Pydantic-based validation.
⚡
FastAPI
Express.js → FastAPI
Async, auto OpenAPI/Swagger docs, Pydantic validation built in. Fastest Python web framework.
🍃
Beanie (ODM) + Motor
Mongoose → Beanie + Motor
Beanie is an async ODM built on Motor (async MongoDB driver). Pydantic-based document models.
🔐
python-jose + passlib
jsonwebtoken + bcrypt → python-jose + passlib[bcrypt]
JWT signing/verification and bcrypt hashing, production-tested Python libraries.
🛡️
slowapi + httpx
express-rate-limit + axios → slowapi + httpx
slowapi for rate limiting, httpx for async HTTP calls to Google Maps API.
📄
Pydantic v2
No Node equivalent → Pydantic schemas
Request/response validation schemas. Replaces manual Joi/Zod validation. Auto-generates API docs.
📦
requirements.txt
package.json → requirements.txt / pyproject.toml
fastapi, beanie, motor, python-jose[cryptography], passlib[bcrypt], httpx, slowapi, python-dotenv

05
Non-Functional Requirements
Quality attributes
Performance
Page Load < 3s
On 4G mobile connections. Google Maps tiles excluded from timing. Images served as WebP with lazy loading.
Scalability
500+ Concurrent Users
FastAPI async + MongoDB Atlas handles MVP load. Scale horizontally on Antigravity when needed.
Availability
99.5% Uptime
Managed via Antigravity hosting. MongoDB Atlas multi-region replication. Health check endpoint at /api/health.
Security
HTTPS + JWT Auth
python-jose JWT (7-day expiry). bcrypt password hashing. Input validation via Pydantic. Google Maps API key domain-restricted.
Usability
Bilingual UI
English + বাংলা toggle in navbar. Hind Siliguri font for Bangla text. All destination names in both scripts.
Compatibility
Mobile-First
Responsive from 320px up. Map + sidebar stack vertically on mobile. PWA-ready for offline budget access.
SEO
Crawlable Pages
Each destination a static route: /destination/coxsbazar. Open Graph tags + meta descriptions in Bangla + English.
Accessibility
WCAG 2.1 AA
Color contrast ratio ≥ 4.5:1. Keyboard navigation. ARIA labels on map markers. Screen reader support.

REST API Contract
Endpoints (FastAPI Routers)
All responses follow: { "success": true, "data": {...} } — must match what Stitch frontend consumes.
Auth /api/auth
POST/api/auth/registerCreate account
POST/api/auth/loginEmail/password login → JWT
POST/api/auth/googleGoogle OAuth token → JWT
GET/api/auth/meReturn current user (auth required)
Destinations /api/destinations
GET/api/destinationsAll 64 districts summary
GET/api/destinations/{slug}Full destination document
GET/api/destinations/{slug}/budgetBudget templates for city
Places (Google Maps Proxy) /api/places
GET/api/places?lat=&lng=&type=&radius=Nearby places (cache-first)
GET/api/places/{place_id}Place details for info panel
Budget /api/budget
POST/api/budget/estimateBody: {slug, travelers, tier} → cost breakdown
Trips /api/trips (auth required)
GET/api/tripsUser's saved trips
POST/api/tripsCreate new trip
GET/api/trips/{id}Single trip (ownership verified)
PUT/api/trips/{id}Update stops / budget
DELETE/api/trips/{id}Soft delete
POST/api/trips/{id}/shareGenerate public share link

Antigravity Prompt
Python/FastAPI Backend Prompt
Paste into Antigravity after importing the Stitch frontend design. This generates the Python backend that exactly serves the frontend.
antigravity-backend-prompt.txt
Build the complete Python/FastAPI backend for Bangladesh Bhromon travel planner. Must match the Stitch-generated frontend exactly. Follow MVC architecture. TECH STACK: - FastAPI (async web framework) - Beanie ODM + Motor (async MongoDB driver) - python-jose[cryptography] for JWT - passlib[bcrypt] for password hashing - httpx for async Google Maps API calls - slowapi for rate limiting - Pydantic v2 for all schemas - Python-dotenv for environment config MODELS (app/models/) — Beanie Documents: user.py: id, name, email (unique), password_hash, google_id, saved_trips[], created_at trip.py: id, user_id, title, destination_slug, travelers, days[{day_number, date, stops[{place_id, note, arrival_time}]}], budget{transport, hotel, food, activities, total}, share_token, created_at destination.py: slug (unique), name_en, name_bn, division, lat, lng, budget_templates{budget{}, midrange{}, luxury{}}, popular_spots[], tips[], cover_image_url, best_time_to_visit, description_en, description_bn place_cache.py: google_place_id (unique), name, place_type, lat, lng, address, rating, photo_url, destination_slug, cached_at (TTL index: 7 days) ROUTERS (app/routers/) — one file per domain: auth_router.py POST /api/auth/register → validate via Pydantic RegisterSchema → hash password with passlib → insert User → return JWT POST /api/auth/login → verify email + bcrypt hash → return JWT + user dict POST /api/auth/google → verify Google ID token → upsert User → return JWT GET /api/auth/me → Depends(get_current_user) → return user destination_router.py GET /api/destinations → return all (slug, name_en, name_bn, division, cover_image_url) GET /api/destinations/{slug} → return full Destination document GET /api/destinations/{slug}/budget → return budget_templates places_router.py GET /api/places?lat=&lng=&type=&radius= → Check PlaceCache first (cached_at > now - 7 days) → Cache miss: call Google Places Nearby Search via httpx → type mapping: hotel→lodging, restaurant→restaurant, bus→bus_station, bike→bicycle_store → Normalize: {place_id, name, type, lat, lng, address, rating, photo_url, distance} → Cache results in PlaceCache collection → Return normalized list GET /api/places/{place_id} → Google Place Details budget_router.py POST /api/budget/estimate Body: BudgetEstimateSchema { destination_slug, travelers: int, tier: Literal["budget","midrange","luxury"] } → Fetch destination.budget_templates[tier] → Multiply per-person costs × travelers → Return: { per_person: {}, totals: {}, grand_total: int } trip_router.py (all routes: Depends(get_current_user)) GET /api/trips → user's trips from user_id in JWT POST /api/trips → create Trip document GET /api/trips/{id} → verify user_id ownership → return PUT /api/trips/{id} → partial update (days, budget) DELETE /api/trips/{id} → soft delete (set deleted_at) POST /api/trips/{id}/share → generate UUID share_token → return share URL MIDDLEWARE (app/middleware/): - auth_middleware.py: FastAPI Dependency → extract Bearer JWT → python-jose decode → attach user to request - rate_limiter.py: slowapi Limiter → 100 req/min per IP MAIN (app/main.py): - Initialize FastAPI app - Include all routers with /api prefix - Initialize Beanie with all Document models on startup - Add CORS middleware (allow Stitch frontend domain + localhost:3000) - Add slowapi rate limiting - Health check: GET /api/health → { status: "ok" } SEED (seed/seed_destinations.py): Pre-populate Destination collection for all 8 divisions. Include realistic BDT budget_templates: - Cox's Bazar: budget{transport:800,hotel:500,food:400}, midrange{transport:1500,hotel:1500,food:800}, luxury{transport:3000,hotel:5000,food:2000} - Sylhet: budget{transport:600,hotel:400,food:350}, midrange{transport:1200,hotel:1200,food:700} - Bandarban, Sajek, Sundarbans, Kuakata, Srimangal — include lat/lng + tips in both English and Bangla RESPONSE FORMAT (must match Stitch frontend exactly): Success: { "success": true, "data": {...} } Error: { "success": false, "message": "...", "code": 400 } List: { "success": true, "data": [...], "count": N } ENV VARIABLES (.env.example): MONGO_URI, JWT_SECRET, JWT_EXPIRES_DAYS=7, GOOGLE_MAPS_API_KEY, GOOGLE_CLIENT_ID, PORT=8080, CLIENT_URL GENERATE: 1. All files in the MVC folder structure above 2. requirements.txt with pinned versions 3. Full Pydantic schemas for all requests/responses 4. seed_destinations.py with realistic Bangladesh data 5.
